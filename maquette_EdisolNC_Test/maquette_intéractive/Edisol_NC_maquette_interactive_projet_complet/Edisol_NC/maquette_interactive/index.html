L’entreprise

Une entreprise locale, une organisation claire.

ÉDYSOL est une entreprise de nettoyage installée à Normandie, Nouméa. Elle accompagne les particuliers et les professionnels, pour une intervention ponctuelle ou un entretien régulier.

  • 2contrôleuses encadrent les équipes sur le terrain.
